# Демонстрация для собеседования

**00:00–00:40.** Откройте ServiceHub под analyst. Выберите FR-014 на рабочем столе и перейдите к его зависимостям. Назовите бизнес-правило: руководитель подтверждает чувствительные заявки.

**00:40–02:00.** Из карточки FR-014 создайте запрос, переведите его на анализ и выберите v1. Покажите API-07 на глубине 1, DB-02 на глубине 3 и TC-11 на глубине 4. Выберите строку, чтобы выделить объясняющий путь. Объясните, почему оценка аналитика сохраняется отдельно.

**02:00–03:20.** Согласуйте CR независимой ролью. Создайте v2, выбрав согласованный запрос в форме новой редакции, измените описание и критерии. Отправьте редакцию и утвердите её под reviewer. Сравните v1 и v2.

**03:20–04:00.** Под manager зафиксируйте baseline. Сравните с ServiceHub 1.0, покажите поля «Было» и «Стало» для версии и описания. В разделе «Связи» покажите устаревшую привязку теста.

При повторной записи восстановите отдельный стенд командой `scripts/lab reset`. [Скриншоты](../../assets/screenshots)
