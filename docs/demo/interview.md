# Демонстрация для собеседования

**00:00–00:40.** Откройте ServiceHub под analyst. Покажите FR-014 и граф. Назовите бизнес-правило: руководитель подтверждает чувствительные заявки.

**00:40–02:00.** Создайте учебный запрос, начните анализ и выберите v1. Покажите API-07 на глубине 1, DB-02 на глубине 3 и TC-11 на глубине 4. Выберите строку, чтобы выделить объясняющий путь. Объясните, почему оценка аналитика сохраняется отдельно.

**02:00–03:20.** Согласуйте CR независимой ролью. Создайте v2 с ID согласованного CR, измените описание и критерии. Отправьте редакцию и утвердите её под reviewer. Сравните v1 и v2.

**03:20–04:00.** Под manager зафиксируйте baseline. Сравните с ServiceHub 1.0, покажите изменившийся version ID и устаревший pin теста. Откройте JSON отчёта.

При повторной записи восстановите отдельный стенд командой `scripts/lab reset`. [Скриншоты](../../assets/screenshots)
