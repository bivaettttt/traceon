# Состояние проекта / Project status

Реализованы API и веб-интерфейс Traceon, PostgreSQL, типизированный граф, воспроизводимый анализ влияния, согласование, baseline, аудит, экспорт и изолированная лаборатория. [Результаты](testing/results.md) фиксируют локальные проверки. Статус опубликованного коммита доступен в [GitHub Actions](https://github.com/bivaettttt/traceon/actions).

Рабочий стол трассируемости связывает реестр, редакции, граф, анализ, согласование и сравнение baseline. [Решения интерфейса](architecture/workbench.md) · [Галерея](../assets/screenshots)
