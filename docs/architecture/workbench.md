# Traceability Workbench

## Контекст и рабочие представления

Рабочий стол связывает выбранное требование с текущей редакцией, зависимостями, исходной версией для Impact Analysis и очередями проекта. Выбор фиксируется в URL. Карточка показывает состояние редакции, версию, номер правки, приоритет, связанные запросы и историю согласования. Из утверждённого запроса можно открыть форму новой редакции со связанным CR.

| Задача | Поведение |
| --- | --- |
| Найти и вернуться | Подтверждённые поиск, фильтры, сортировка, группировка и смещение реестра живут в URL. Карточка возвращает этот контекст. |
| Выгрузить данные | JSON и CSV выгружают весь реестр проекта по действующему контракту. Область выгрузки указана в названии кнопок. |
| Изучить зависимости | Компоновка XYFlow группирует узлы по расстоянию. Из карточки видны ближайшие узлы, переключатель открывает весь проект. В инспекторе и списке показаны типы и фактические направления связей. |
| Объяснить влияние | Выбор находки показывает путь по сохранённому снимку, исходное направление каждого ребра, признак обхода против стрелки, глубину, актуальность и оценку. Риск вводится в CR. |
| Согласовать решение | Карточка CR показывает текущий этап и его предпосылки. Очередь ревью открывает конкретную назначенную редакцию. Backend отвечает за доступ, переходы и целостность. |
| Сравнить снимки | A показывает «Было», B показывает «Стало». Для требований, артефактов и связей видны добавление, удаление и изменения полей. Отсутствующее поле, null и пустая строка подписаны отдельно. Полный JSON доступен по раскрытию. |

| Область | Решение |
| --- | --- |
| Типографика | IBM Plex Sans 400/500/600. Текст 16/24 px, таблица 14/21 px, H1 25–32 px, H2 около 17 px. IBM Plex Mono для кодов и версий. |
| Цвет | Canvas `#F7F6F9`, белые поверхности, текст `#211A32`, вторичный текст `#5B5267`, акцент `#4E3486`, навигация `#211A35`. |
| Состояния | Успех `#185844` на `#E5F3ED`, внимание `#684208` на `#FFF0D0`, ошибка `#842D3D` на `#FBE9EE`. Название состояния остаётся видимым. |
| Отступы и контуры | Шкала 4/8/12/16/24/32 px. Линия контролов `#82778D`, функциональные панели с радиусом 8 px. Фокус `#6539B0` на светлом и `#D8C6FF` в тёмной навигации. |
| Граф | Фокус, выбор, устаревание и путь различаются контуром, стрелкой, пунктиром, толщиной и текстом. Узел выбирается кликом, Enter или Space. |

| Motion | Интерфейс сохраняет статический индикатор фокуса и выбора при `prefers-reduced-motion: reduce`. |

## Решения по рекомендациям аудита

- Область CSV оставлена на уровне всего реестра, потому что существующий экспорт не применяет фильтры таблицы. В интерфейсе область выгрузки названа явно.
- Типы рёбер перенесены в инспектор и список связей, чтобы код и подпись узла оставались читаемыми. Геометрия раскладки и порядок обхода независимы от направления ребра.
- Структурный diff показывает поля, которые имеют смысл для пользователя. Иногда меняются только служебные атрибуты. Полная версия отчёта сохраняет их в техническом раскрытии.
- Рабочий стол использует существующий API реестра. Локальный поиск охватывает загруженную страницу. Ссылка на реестр переносит поисковую строку для поиска по проекту.
